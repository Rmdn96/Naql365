## Activation

1. Verify the live release and database migration inventory against the selected baseline. Prepare a restorable backup and review the pending commercial-admin and quote migrations with the owner. Do not assume that GitHub's deployment branch is already installed.
2. Apply the approved migrations and preserve existing access-hook configuration. Verify the single active Super Admin and recovery on the target environment before activating the Auth and PostgREST access gates. Establish a rollback for these hooks and the release manifest.
3. Deploy the approved build with server-side NAQL365_STORE_QUOTE_MODE=true. Keep fixed checkout and collection paused. A separately controlled singleton in private.store_quote_launch gates anonymous quote visibility and submissions, and is closed until explicitly approved.
4. Review the real public copy, product revisions, media, kit components and Cairo/Giza availability. Confirm contact, delivery and return terms. Set the private launch gate only when the owner approves. In Orders → Product quote requests, the operator prepares an itemized EGP offer, sends it through the approved customer contact channel, and records the customer's consent to the exact saved version.
5. The request and documented consent are upstream of order creation. The system does not automatically convert them into an order, reserve stock, send messages, or initiate payment. The existing fixed-price purchase and four manual payment channels remain separate and can continue in the fixed-price release after approval. Use approved accounting and order operations before collecting on a quote.
6. To roll back, close the quote launch gate first, restore the prior release configuration and keep quote requests, offer audit records, previous orders and payments intact. A replay of an existing valid nonce and identical submission can return its existing reference. New intake remains closed.

SEO uses canonical and alternate URLs based on the application's configured origin. A gated product revision is required for inclusion in the quote sitemap. The quote pages emit no priced Offer, stock claims or ratings.

## Category artwork

The category editor uses the same private WebP bucket as listing images. Upload a reviewed source into the matching category's image panel with its rights reference. A new or replacement image stays private until explicitly approved. In quote mode an approved image is public only while the quote gate is open, the category is published, and it contains an approved quote product. Removing or replacing an image retires its existing URL without deleting the audit history.

Match the eight source files in the Visual Assets V2 archive by category slug: `box → 06-Categories/BOX.webp`, `bbl → BBL.webp`, `str → STR.webp`, `tap → TAP.webp`, `rol → ROL.webp`, `bag → BAG.webp`, `twi → TWI.webp`, and `kit → KIT.webp`. The storefront follows this sequence, with products ordered by SKU inside each category and bundles last. The supplied artwork remains outside the public asset directory.

## Design System V2 direction

Arabic-first Alexandria and English Inter; logical RTL/LTR spacing. Deep navy anchors the brand, restrained electric blue identifies actions, cyan marks route accents, slate and layered neutral surfaces provide hierarchy. Use accessible action variants rather than low-contrast brand-colored body text. Public editorial layouts can be generous; operational interfaces will remain compact in later waves.

Define separate V2 semantic variables for color, surfaces, type scale, spacing, restrained control/card radii, elevation, focus, status and density. Keep existing accepted tokens stable until each surface adopts V2. Buttons, fields, tables, cards, dialogs/drawers, tabs, timelines, loading/skeleton, empty/error/success and mobile patterns share these semantics. Status requires text/icon, never color alone. Existing primitives retain their accepted semantics and authority.

Public storytelling uses an explicitly illustrative Pickup → Planning → Driver → Transit → Delivery route motif, not simulated live shipment data. No fake totals, testimonials, certificates, ETA, GPS or stock-truck imagery. Public availability still comes from existing activated services/cities. SA is Riyadh-origin, EG is Cairo-origin; no cross-Market freight or nationwide promise. No preliminary monetary estimate. Proof submission is not payment confirmation. A reference is not authorization. Legal content is not invented.

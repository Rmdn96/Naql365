# إطلاق متجر نقل 365

نقطة التراجع قبل التغيير هي `0c4bd2e6fb01332e23a2afd612ad16f051c4e6d4`. يتطلب إطلاق البيع موافقة مستقلة بعد قبول النسخة المعزولة.

## بيانات يقدمها المالك

- فئة ومنتج فعليان على الأقل، مع اسم ووصف عربي وإنجليزي، صورة يحق نشرها، سعر تجزئة بالجنيه وحالة توفر مؤكدة.
- المورد الفعلي وعرضه الساري واتفاق التنفيذ، مع المسؤول عن التوصيل والتحصيل والمرتجعات.
- اعتماد سياسات النشر والبيع والتوصيل والضرائب والمرتجعات. يحدد عقد الشراء الساري نطاق القاهرة والجيزة وكيفية احتساب الضريبة واستحقاق المورد. يراجع الموظف التوفر ويسجّل رسوم التوصيل وموافقة العميل قبل التجهيز.
- حساب بنكي مصري معتمد باسم المستفيد الصحيح، ومسؤول مالي مخول بالتحقق من القيد البنكي والتحصيل. يرسل الموظف بيانات التحويل بعد موافقة العميل على الإجمالي.
- تأكيد رقم الهاتف وواتساب المنشورين، والشخص المسؤول عن الرد. تنشر ساعات العمل بعد اعتمادها.

## التحقق والتراجع

1. طبّق التغييرات أولًا على قاعدة محلية فارغة وعلى قاعدة اختبار تحتوي على طلب مسجل سابقًا. افحص بقاء سجلات الطلبات والتحصيل والتدقيق القديمة قابلة للقراءة وفق صلاحياتها.
2. اختبر الطلب المكرر، الأسعار المتغيرة، الإيقاف، منع الاطلاع على طلب عميل آخر، وتحقق من المسارين الماليين حتى التحصيل. اختبر عرض السعر اليدوي للنقل بصورة مستقلة.
3. قبل فتح المتجر، يختبر موظف مخول الدخول والاستعادة والوصول إلى لوحة الطلبات. لتشخيص العطل الإنتاجي المبلغ عنه، طابق زمن محاولة مصرح بها مع سجل Server Action ورمز Supabase وحدث Resend. سجل زمن الحدث ورمزه فقط. نجاح بناء التطبيق أو رسالة الاستعادة العامة لا يثبتان تسليم البريد.
4. عند الترخيص بالإطلاق، احتفظ بالحزمة الحالية وهويتها، وطبّق ترحيل قاعدة البيانات المراجع أولًا مع بقاء النشر التجاري موقوفًا. تحقق من الحزمة الجديدة وهوية الإصدار وقراءة السجلات القديمة، ثم اختبر العمليات المصرح بها قبل فتح النطاق.
5. عند ظهور خطأ في السعر أو التحصيل، أوقف استقبال الطلبات الجديدة باستخدام إجراء الإيقاف الحالي. احتفظ بكل الطلبات والمراجع والمبالغ وسجل التدقيق. راجع الطلبات المعلقة قبل استعادة واجهة سابقة. تتطلب استعادة التطبيق مطابقة حزمة الإصدار وBackend Attestation. لا تحذف بيانات مالية لترجيع الترحيل.

## معيار قرار الإطلاق

قبول الشراء والتحصيل في البيئة المعزولة، دخول موظف فعلي واستعادته لحسابه، جاهزية بيانات البيع الحقيقية، وتسمية الموظف الذي يتابع كل طلب. تبقى مراجعة التحويل وتأكيد العميل عمليتين منفصلتين.
